# Muse DSL 用户指南

Muse 让你用几行代码写节奏、旋律和循环音乐。本指南中的代码可以直接粘贴到编辑器，点击 **Run** 试听；每次修改后再次运行，就会更新正在播放的音乐。

打开 [Muse Web UI](https://muse.20070809.xyz)，使用已有的站点账号登录。默认示例是 **Canon in D**，速度为 **90 BPM**。想从头练习，可以先选中编辑器内容，再粘贴下面的例子。切换示例会备份当前草稿，**restore previous draft** 可以恢复它。

## 1. 写出第一段节奏

粘贴这一行并点击 **Run**：

```js
"bd ~ sn ~"
```

`bd` 是底鼓，`sn` 是军鼓，`~` 是休止。四个位置依次播放，再从头循环。

加入踩镲：

```js
stack(
  "bd ~ sn ~",
  gain(0.3, "hh*8")
)
```

`stack` 让几条声部同时播放。`hh*8` 表示每个周期触发八次踩镲；`gain(0.3, …)` 把这一层的音量调低。

| 操作 | 方法 |
| --- | --- |
| 运行或更新音乐 | Run，或 Ctrl+Enter / Cmd+Enter |
| 停止 | Stop，或 Ctrl+. / Cmd+. |
| 继续播放已安装的音乐 | Play |
| 调整整体速度 | 修改 BPM |
| 下载音频 | 填写 seconds，选择 format，点击 download … |

编辑后要用 **Run** 才会更新音乐；**Play** 继续播放上一次成功运行的内容。

## 2. 理解周期与速度

Muse 用 **cycle（周期）** 描述时间。一个普通字符串把一个周期分成若干等长位置。

例如 `"bd ~ sn ~"` 分成四份：底鼓在开头，军鼓在一半的位置。添加更多音符会增加同一周期里的密度，不会自动延长整段音乐。

当前 Muse 的 BPM 表示**每分钟多少个周期**：

| BPM | 一个周期的时长 |
| --- | --- |
| 60 | 1 秒 |
| 90 | 约 0.667 秒 |
| 120 | 0.5 秒 |

想把四个音符当作四拍，使用 `.slow(4)`，让整段占四个周期：

```js
note("d4 e4 f#4 a4")
  .slow(4)
  .sound("tri")
  .cutoff(3000)
  .gain(0.4)
```

在 90 BPM 下，这段旋律约 2.67 秒循环一次，每个音符约 0.667 秒。

`fast(2, pattern)` 把时间压缩为一半；`slow(2, pattern)` 把时间拉长为两倍。它们改变这一条声部的节奏，不改变界面上的 BPM。

## 3. 字符串里的音乐语法

### 顺序、休止与重复

| 写法 | 含义 |
| --- | --- |
| `"bd sn hh"` | 一个周期内依次播放三个音 |
| `"bd . sn ~"` | `.` 和 `~` 都占据一个休止位置 |
| `"hh*4"` | 每个周期触发四次踩镲 |
| `"bd/2"` | 把底鼓循环拉长到两个周期 |
| `"[bd sn]/2"` | 把整个底鼓、军鼓序列拉长到两个周期 |
| `"(bd hh)"` | 底鼓与踩镲同时触发 |
| `"<bd sn>"` | 一个周期选底鼓，下一个周期选军鼓 |

`/2` 改变的是触发时间和事件时长；鼓声音本身的长短还由鼓音色的衰减决定。

### 分组

方括号 `[ ]` 把内容组成一条序列，可对整组使用 `*` 或 `/`。圆括号 `( )` 表示同时发声，适合写和弦；尖括号 `< >` 表示逐周期轮换。

当前版本中，内层序列放进外层片段后不会自动重新等分该片段。例如，想在前半段放底鼓、后半段放两个踩镲，可以写：

```js
p("bd [hh*4]")
```

它会在周期的 `0`、`1/2`、`3/4` 位置触发。`"bd [hh hh]"` 当前只会在后半段保留一个踩镲，不能用来替代上例。编写复杂细分时，优先使用明确的休止、重复倍数和 `stack`。

### p：把字符串变成可继续加工的 pattern

字符串可以直接交给 `stack`、`gain` 等函数。如果想使用链式写法，先用 `p`：

```js
p("bd ~ sn ~").slow(4).gain(0.7)
```

普通 JavaScript 字符串没有 Muse 的 `.gain` 方法，因此 `"bd".gain(0.5)` 不可用。

## 4. 旋律与和弦

### 用音名写旋律

```js
note("d4 e4 f#4 g4 a4 b4 c#5 d5")
  .slow(8)
  .sound("tri")
  .cutoff(3000)
  .gain(0.4)
```

音名格式是**字母 + 可选升降号 + 八度数字**：

| 写法 | 音高 |
| --- | --- |
| `c4` | 中央 C，MIDI 60 |
| `a4` | MIDI 69 |
| `f#4` | 升 F |
| `eb4` | 降 E |
| `c3` | 比 `c4` 低一个八度 |

音名字母可以大写或小写。使用 `#` 和字母 `b` 表示升降号，不使用 `♯`、`♭`。音名一定要带八度：`d4` 是音符，单独的 `d` 会被当作音色名称。

也可以用 MIDI 数字：

```js
note("60 62 64 67").slow(4).sound("sine").cutoff(2200).gain(0.4)
```

### 写和弦

把同时发声的音放在圆括号里：

```js
note("(d3 f#3 a3) (a2 c#3 e3)")
  .slow(8)
  .sound("organ")
  .attack(0.08)
  .release(0.25)
  .cutoff(2500)
  .gain(0.2)
```

两个和弦各占四个周期，总共八个周期后重复。和弦同时发出的声音更多，适合从较低音量开始调整。

### 指定音高与移调

`note(72, pattern)` 把这条声部的所有事件设为 MIDI 72；`transpose(12, pattern)` 则在已有音高上加 12 个半音。

```js
note("d3 f#3 a3")
  .slow(3)
  .transpose(12)
  .sound("tri")
  .cutoff(3000)
  .gain(0.4)
```

`transpose(12)` 升高一个八度，`transpose(-12)` 降低一个八度。若想保留旋律音程，使用 `transpose`。

`note("d4 e4")` 创建音符序列；`note(72, p("x*4"))` 给已有节奏设定单一音高。`note("d4 e4", pattern)` 当前不支持。链式 `.note("d4 e4")` 会创建新的音符序列，不保留前面声部的设置；写旋律时优先从 `note("…")` 开始。

## 5. 组合多个声部

| 函数 | 用途 | 例子 |
| --- | --- | --- |
| `stack(a, b)` | 同时播放多层 | 鼓和贝斯 |
| `cat(a, b)` | 一个周期内分段使用各声部 | 简单底鼓、军鼓序列 |
| `alt(a, b)` | 按完整周期轮换声部 | 两种鼓型交替 |

简单顺序：

```js
cat("bd", "sn", "hh", "~")
```

两种鼓型轮换：

```js
alt("bd ~ sn ~", "bd hh sn hh").slow(4)
```

`cat` 中的复杂子序列遵循前面的分组规则，不会自动把整个子序列压缩到对应片段。若要完整地轮流播放两种鼓型，使用 `alt`。

可以用 `const` 给声部起名字。最后一条语句要返回你想播放的 pattern：

```js
const drums = p("bd ~ sn ~").slow(4).gain(0.65);
const hats = p("hh*8").slow(4).gain(0.2);
const bass = note("d2 a1 b1 f#1")
  .slow(4).sound("sine").cutoff(600).gain(0.5);

stack(drums, hats, bass)
```

这些 pattern 可以复用，方法会返回新的 pattern。`const quiet = drums.gain(0.2)` 不会修改 `drums` 本身。

## 6. 选择音色

用 `sound("名称", pattern)` 或 `pattern.sound("名称")` 选择音色：

| 名称 | 声音 |
| --- | --- |
| `bd` | 底鼓 |
| `sn` | 军鼓 |
| `hh` | 闭合踩镲 |
| `oh` | 开放踩镲 |
| `cp` | 拍手 |
| `tom` | 通鼓 |
| `sine` | 正弦波，圆润的单音 |
| `tri` | 三角波 |
| `saw` | 锯齿波 |
| `square` | 方波 |
| `pulse` | 窄脉冲波 |
| `organ` | 多个谐波叠加的音色 |
| `noise` | 噪声 |
| 自己加载的名称 | 自定义音频采样 |

只写音符时默认使用 `saw`。未识别的音色名称当前也会回退到 `saw`；名称拼错不会自动变成静音。

```js
note("d3 a3 b3 f#3")
  .slow(4)
  .sound("pulse")
  .cutoff(1200)
  .gain(0.35)
```

## 7. 音量、声像与音色控制

控制可以用函数或链式方法书写：

```js
gain(0.4, sound("tri", note("d4 f#4 a4"))).cutoff(3000)
```

同样的设置也可以写成：

```js
note("d4 f#4 a4").sound("tri").gain(0.4).cutoff(3000)
```

| 控制 | 作用 | 入门值 |
| --- | --- | --- |
| `gain(v)` | 音量，`0` 静音 | `0.2–0.7` |
| `pan(v)` | 声像：`0` 左，`0.5` 中，`1` 右 | `0.25` / `0.75` |
| `cutoff(hz)` | 滤波频率；多数旋律音色用它调整明亮程度 | `600–4000` Hz |
| `res(v)` | 滤波共振 | `0.1–0.4` |
| `speed(v)` | 振荡器或采样的速度；会影响音高 | `0.5` / `1` / `2` |
| `crush(v)` | 量化与采样保持效果，`0` 关闭 | `0.1–0.4` |
| `delay(v)` | 送入延迟的量，`0` 关闭 | `0.1–0.4` |

`speed` 不改变音符的触发节奏。想让节奏更快，使用 `fast`；想让采样播放更快、音高更高，使用 `speed`。鼓音色还有各自的滤波方式，`cutoff` 对底鼓不起滤波作用。

**重复设置同一个控制，后面的值会覆盖前面的值。** `.gain(0.5).gain(0.2)` 的最终音量是 `0.2`。对 `stack(...).gain(0.3)` 的设置也会把各层的音量统一为 `0.3`；要保留声部之间的音量差，把 `gain` 分别放在各层上。

### 声音如何起落：包络

| 控制 | 含义 | 单位 |
| --- | --- | --- |
| `attack(v)` | 从无声升至峰值的时间 | 秒 |
| `decay(v)` | 从峰值下降到持续电平的时间 | 秒 |
| `sustain(v)` | 音符持续阶段的电平 | `0–1` |
| `release(v)` | 音符结束后逐渐收尾的时间 | 秒 |

柔和的持续音：

```js
note("(d3 f#3 a3)")
  .slow(4)
  .sound("organ")
  .attack(0.25)
  .decay(0.15)
  .sustain(0.6)
  .release(0.5)
  .cutoff(2200)
  .gain(0.2)
```

鼓音色会使用自己的衰减形状，`sustain` 固定为零。调整鼓的长短时，优先尝试 `decay`；`attack` 和 `release` 也可以调整。

## 8. 让节奏发生变化

### 加速、减速、反转和移位

```js
p("bd ~ sn hh").fast(2).gain(0.5)
```

```js
p("bd ~ sn hh").rev().slow(4).gain(0.5)
```

`rev` 在每个周期内反转事件顺序；`shift` 按周期移动位置。正数向后移，负数向前移：

```js
stack(
  p("bd").gain(0.6),
  p("sn").shift(0.5).gain(0.35)
).slow(4)
```

上例底鼓与军鼓相隔两个周期。`shift(0.5)` 先移动半个周期，再由外面的 `slow(4)` 把时间拉长四倍。

### every：定期变化

每隔四个周期，使用加速后的版本：

```js
every(4, q => q.fast(2), p("bd ~ sn hh")).gain(0.5)
```

也可以链式书写：

```js
p("bd ~ sn hh").every(4, q => q.fast(2)).gain(0.5)
```

周期编号从 `0` 开始，因此 `every(4, …)` 在 `0、4、8…` 周期生效。它按当时的周期判断；将整个结果再 `.slow(4)`，也会把变化间隔拉长四倍。

`q => q.fast(2)` 表示“拿到当前 pattern，再返回它的加速版本”。Muse 的 `fast` 需要倍数和 pattern 两个参数，不能把 `fast(2)` 当作这样的变换函数传入。

### sometimes：偶尔变化

```js
p("bd ~ sn hh").sometimes(0.5, q => q.rev()).gain(0.5)
```

每个周期有约一半概率使用反转版本。概率用 `0–1`：`0` 一直用原版，`1` 一直用变换版。相同代码、相同周期的选择是固定的，重新播放会得到同样的变化序列。

### chunk：变化位置逐段移动

```js
p("hh*4").chunk(4, q => q.fast(2)).gain(0.25)
```

把周期分成四段，每个周期只对一段使用变换。生效段依次是第一、第二、第三、第四段，再重复。

### euclid：均匀分布的鼓点

```js
stack(
  euclid(3, 8, "bd").gain(0.65),
  euclid(5, 8, "hh", 1).gain(0.25)
).slow(4)
```

`euclid(k, n, pattern, rotation)` 把 `k` 次击打分布在 `n` 个位置中。`euclid(3, 8, "bd")` 对应 `x..x..x.`；第四个参数让位置旋转，省略时为 `0`。入门时使用 `0 ≤ k ≤ n` 的整数和非负整数旋转量。

### struct：自己指定击打位置

```js
struct("x..x..x.", "bd").slow(4).gain(0.6)
```

在这个掩码里，`x` 表示发声，`.` 表示休止。每个字符都占一个位置；不要插入空格，也不要用 `~` 当掩码休止。对已有复杂节奏使用 `struct` 时，它保留选定位置里的事件，并可能缩短事件持续时间。

## 9. 回声与合唱

### delay：固定时间的延迟

```js
note("d4 ~ f#4 ~")
  .slow(4)
  .sound("sine")
  .cutoff(2200)
  .gain(0.35)
  .delay(0.25)
```

`delay` 的参数是送入延迟的量，不是延迟秒数。当前延迟间隔约 0.4 秒，反馈固定；调整 BPM 不会改变这个间隔。

### echo：跟随周期的重复

```js
note("d4 ~ ~ ~")
  .slow(4)
  .sound("tri")
  .cutoff(3000)
  .echo(3, 0.5, 0.4)
```

`echo(次数, 间隔周期, 反馈比例, pattern)` 包含原声，再加入若干个移位的重复声部。上例增加三次重复，间隔半个周期，重复层的音量依次为 `0.4、0.16、0.064`。

次数允许整数 `0–8`，间隔必须大于零，反馈比例允许 `0–1`。链式写法还可以使用 `.echo()`，默认是 `3` 次、间隔 `0.25` 周期、反馈 `0.5`。

原声保留原来的 `gain`；重复声部会设定自己的 `gain`，覆盖它们原有的音量。`echo` 复制整个 pattern，因此声部本身也会继续循环，不是只回响一次后结束。

### chorus：左右轻微失谐

```js
note("(d3 f#3 a3)")
  .slow(4)
  .sound("organ")
  .cutoff(2200)
  .chorus(0.01)
```

`chorus(depth, pattern)` 加入左右两条轻微失谐的声部。深度允许 `0–0.1`；链式 `.chorus()` 默认深度是 `0.01`。

它给原声设置 `gain(0.5)`，给左右层各设置 `gain(0.25)`。左右层还会设置自己的 `speed` 和 `pan`，覆盖此前这些控制的值。先从小深度开始，试听后再调整。

## 10. 使用自己的音频

在页面中填写采样名称，例如 `my_sample`，点击 **load audio** 选择音频文件，然后运行：

```js
sound("my_sample", "x*4").slow(4).gain(0.5).cutoff(3000)
```

`x` 在这里用来提供触发位置；外面的 `sound` 把这些位置的音色设为 `my_sample`。单独写 `"x"` 不会自动使用你的采样。

采样名称以字母开头，只能含英文字母、数字和下划线，最多 127 个字符。文件须能被浏览器解码，长度最多 30 秒、大小最多 50 MiB；多声道会混合为单声道。

```js
sound("my_sample", "x*4")
  .slow(4)
  .speed(2)
  .pan(0.75)
  .cutoff(3000)
  .gain(0.4)
```

`speed(2)` 使采样以两倍速度读取，音高升高一个八度。`note(72, pattern)` 也能将采样相对默认 MIDI 60 升高一个八度，两种设置同时使用会叠加。

采样从头播放一次，不会在单个音符内循环。音符持续时间和包络可能先截断它；采样读完后不会继续产生原始声音，但滤波与延迟可以留下尾音。它会保留到页面刷新，并随浏览器音频导出一起渲染。刷新后需要重新加载，CLI 当前不支持加载采样文件。避免与 `bd`、`sine` 等已有音色同名，否则该名称会使用你的采样。

## 11. 一个可直接演奏的小作品

下面将四拍鼓型、八拍贝斯和旋律组合起来。可从 90 BPM 开始试听：

```js
const drums = stack(
  p("bd ~ sn ~").gain(0.6),
  p("hh*8").gain(0.18)
).slow(4);

const bass = note("d2 a1 b1 f#1 g1 d2 g1 a1")
  .slow(8)
  .sound("sine")
  .cutoff(600)
  .attack(0.015)
  .release(0.12)
  .gain(0.5);

const melody = note("f#4 e4 d4 c#4 b3 a3 b3 c#4")
  .slow(8)
  .sound("tri")
  .cutoff(3000)
  .gain(0.35)
  .pan(0.65)
  .delay(0.15);

stack(drums, bass, melody)
```

先改 `gain` 调整声部平衡，再改音符、休止和音色。默认卡农的完整循环编曲见 [canon.js](../examples/canon.js)；它有三个相隔八个周期的模仿声部，旋律总长 32 个周期，在 90 BPM 下约 21.3 秒循环一次。

## 12. 保存、导出与排错

编辑器会自动保存代码草稿，重新打开同一站点时恢复。代码草稿不包含加载的采样文件。

浏览器导出读取**当前编辑器内容**和当前 BPM，即使它与正在播放的内容不同。填写 `1–300` 秒，从 **format** 选择格式，再点击 **download …**。想保存卡农的一轮，可以选择约 22 秒。

| 格式 | 适合的用途 |
| --- | --- |
| WAV | 未压缩的 16 位音频，适合后续编辑 |
| FLAC | 无损压缩，解码后与 WAV 的样本完全一致 |
| MP3 | 192 kbps，适合分享和一般播放器 |
| OGG | Vorbis 编码，质量等级 5 |
| M4A | MP4 容器中的 AAC，192 kbps |
| AAC | ADTS 容器中的 AAC，192 kbps，文件后缀 .aac |
| MIDI | 保存可继续编辑的音符，适合导入音乐制作软件 |

音频格式均为 48 kHz、双声道，从周期零开始渲染，包含当前加载的采样和音频效果。超出选择时长的尾音会截断；压缩格式可能附带少量编码填充。编码在浏览器本地完成，首次选择压缩格式需要加载编码器，按钮会显示准备和编码状态。

**MIDI 保存的是音符，不是声音。** 它保留节奏、速度、力度和音高，音高会按半音取整；鼓点映射为通用 MIDI 打击乐，其他音色使用近似的通用 MIDI 乐器。采样文件、滤波、包络、声像、音频延迟和 crush 不会写入 MIDI，播放声音取决于接收软件。pattern 层的 echo 和 chorus 会产生相应音符，但同时同音的音符会合并，重叠的同音重复会重新触发。自定义采样会表示为钢琴音符。当前最多支持 15 种旋律音色和 100,000 个音符。

如果使用终端，可以从输出后缀选择格式，或显式指定：

```sh
./muse run examples/canon.js --bpm 90 --seconds 24 -o canon.mp3
./muse run examples/canon.js --bpm 90 --seconds 24 --format midi -o canon.mid
```

CLI 的 MP3、FLAC、OGG、AAC/M4A 导出需要系统安装 FFmpeg；WAV 和 MIDI 不需要。浏览器导出无需安装它。


| 遇到的情况 | 如何处理 |
| --- | --- |
| 页面没有声音 | 点击 Run；确认浏览器标签未静音，并检查控制台提示 |
| 改了代码，音乐没变 | 再次点击 Run；如果报错，修正后再运行 |
| 提示最后一条语句必须是 pattern | 在最后加上 `stack(...)`、变量名或另一条 pattern 表达式 |
| 字符串没有 `gain` 方法 | 改成 `p("…").gain(...)` |
| `every` 中使用 `fast(2)` 报错 | 改成 `q => q.fast(2)` |
| 名称存在但音色不对 | 核对音色拼写；刷新后重新加载自定义采样 |
| 多层音乐变得过响 | 分别降低各层 gain；注意叠加音符和效果的层数 |
| 切换示例后想找回代码 | 点击 restore previous draft |
| 想暂时静音整个 pattern | 最后一行写 `silence`，再点击 Run |

运行失败时会显示错误；能获得行列位置的错误会定位到编辑器。已有音乐通常继续播放，直到你成功运行新代码或点击 Stop。

## 常用写法速查

| 目标 | 写法 |
| --- | --- |
| 字符串转 pattern | `p("bd ~ sn ~")` |
| 多层同时演奏 | `stack(a, b, c)` |
| 简单顺序 | `cat("bd", "sn")` |
| 逐周期交替 | `alt(a, b)` |
| 加速 / 减速 | `pattern.fast(2)` / `pattern.slow(2)` |
| 反转 / 移位 | `pattern.rev()` / `pattern.shift(0.25)` |
| 周期变化 | `pattern.every(4, q => q.fast(2))` |
| 概率变化 | `pattern.sometimes(0.5, q => q.rev())` |
| 分段变化 | `pattern.chunk(4, q => q.fast(2))` |
| 均匀分布鼓点 | `euclid(3, 8, "bd")` |
| 自定义节奏位置 | `struct("x..x..x.", "bd")` |
| 旋律 / 单一音高 | `note("d4 e4")` / `note(62, pattern)` |
| 相对移调 | `pattern.transpose(12)` |
| 音色 | `pattern.sound("tri")` |
| 控制 | `pattern.gain(0.4).cutoff(3000).pan(0.5)` |
| 效果 | `pattern.delay(0.2)` / `pattern.echo(3, 0.25, 0.5)` / `pattern.chorus(0.01)` |
| 无声 pattern | `silence` |

多数变换和控制支持链式写法，或“参数在前、pattern 在后”的函数写法，如 `fast(2, pattern)`。`stack`、`cat`、`alt`、`euclid` 只提供独立函数；它们可以接收字符串，但不能作为 `pattern.stack(...)` 或 `pattern.euclid(...)` 方法调用。
